# 맛잘알 동네지도 결정 문서

작성일: 2026-05-16

## 제품 방향

맛잘알 동네지도는 사용자가 로그인 화면 없이 맛집을 등록하고, 같은 가게에 여러 사람이 리뷰를 쌓는 지도 중심 커뮤니티다. 첫 화면은 소개 페이지가 아니라 지도와 리스트이며, 전국 어디든 등록할 수 있다.

## MVP 범위

- 네이버지도 중심 탐색
- 가게명/주소 검색 후 좌표 확인
- 중복 맛집 후보 표시
- 고정 카테고리와 선택 태그
- 가격대, 추천 메뉴, 좋았던 점, 아쉬운 점, 재방문 의사 기반 리뷰
- 선택 사진 업로드
- 신고 접수와 공개/숨김/삭제 상태
- 같은 익명 세션에서 작성한 맛집/리뷰 수정 및 삭제

## 제외한 것

- 협찬 여부 입력
- 예약, 주문, 결제, 배달 연동
- 팔로우 피드나 실시간 채팅
- 복잡한 인증 기반 회원 프로필

## 기술 결정

- Next.js 15 App Router를 사용한다.
- Supabase Anonymous Sign-In으로 로그인 없는 작성 경험을 만들고, RLS로 작성자 권한을 제한한다.
- Supabase 환경변수가 없을 때도 사용자 맛집/리뷰 데이터를 브라우저 저장소에 저장하지 않는다. 앱은 설정 오류를 명확히 보여준다.
- 네이버지도 키가 없을 때는 fallback 지도를 표시하고, 지오코딩 키가 없을 때는 개발용 fallback 좌표를 반환한다.

## 데이터 모델

- `anonymous_profiles`: 익명 사용자 닉네임
- `places`: 가게명, 주소, 좌표, 카테고리, 태그, 대표 사진, 상태
- `reviews`: 가격대, 추천 메뉴, 좋았던 점, 아쉬운 점, 재방문 의사, 사진, 상태
- `reports`: 가게 또는 리뷰 신고와 처리 상태

## 운영 원칙

등록과 리뷰는 즉시 공개하되, 신고와 관리자 숨김 상태를 통해 품질을 관리한다. 중복 후보는 등록 전에 보여주고, 병합 워크플로는 이후 단계에서 확장한다.
